# Dados sintéticos

**Todos os registros neste diretório são 100% fictícios.** Não contêm dados pessoais reais,
nomes, documentos ou credenciais.

- `cases.json` — gerado por `scripts/prepare_data.py` (não versionar alterações locais se desejar reproducibilidade estrita; o repositório inclui uma versão gerada com seed fixa).
- `gold_fixed.json` — casos-limite com rótulo ouro definido manualmente na especificação da PoC.
- `intake_schema.json` — documentação do formato de entrada.
